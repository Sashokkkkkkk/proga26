# 🌑 Dark Canvas - Темный веб-сервер для блога и изображений

Современный темный интерфейс для публикации статей и изображений с возможностью управления контентом.


## ✨ Особенности

- 🎨 **Темный современный дизайн** с анимациями и градиентами
- 📝 **Создание и редактирование статей** с поддержкой HTML-форматирования
- 🖼️ **Загрузка изображений** через Drag & Drop
- 📱 **Адаптивный интерфейс** для всех устройств
- 🗑️ **Управление контентом** (удаление статей и изображений)
- 🌐 **Доступ с других устройств** в локальной сети
- ⚡ **Быстрый и легкий** - не требует базы данных

🐛 Устранение неполадок
Проблема: "Python не найден"
Решение: Установите Python 3.6 или выше:

Windows: python.org/downloads (галочка "Add to PATH")

macOS: brew install python

Linux: sudo apt install python3

Проблема: Порт занят
Решение: Измените порт в настройках или завершите процесс, использующий порт:

bash
# Windows
netstat -ano | findstr :5000
taskkill /PID [ID] /F

# macOS/Linux
lsof -i :5000
kill -9 [PID]
Проблема: Нет доступа с других устройств
Решение:

Убедитесь, что устройства в одной сети

Используйте правильный IP-адрес (показывается при запуске)

🔧 API Endpoints
Сервер предоставляет следующие API:

Метод	Endpoint	Описание
GET	/api/articles	Список всех статей
GET	/api/images	Список всех изображений
POST	/api/add-article	Добавить новую статью
POST	/api/upload-image	Загрузить новое изображение
POST	/api/delete-article	Удалить статью по ID
POST	/api/delete-image	Удалить изображение по ID
